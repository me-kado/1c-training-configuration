# 1c-training-configuration
Тренировочная конфигурация 1С 8.3.17 для портфолио


Учебная конфигурация на платформе 1С:Предприятие 8.3.17, разработанная в рамках первой тестовой работы по конфигурации 1С согласно техническому заданию.

Конфигурация предназначена для ведения учета выполнения задач исполнителями, контроля сроков, фиксации затраченного времени и автоматического начисления заработной платы.

## 📋 Описание проекта

Проект реализован строго по ТЗ (файл [`docs/tz.pdf`](docs/tz.pdf)). 

**Ключевые возможности системы:**
- **Управление проектами и задачами:** ведение проектов, назначение ответственных, создание задач с указанием важности, сроков и плановых трудозатрат.
- **Рабочее место пользователя:** начальная страница со списком задач, гибкая группировка (по проекту, состоянию, важности) и отборы (свои задачи / задачи своих проектов).
- **Учет времени:** фиксация времени начала и окончания работы над задачей (таймер), автоматический подсчет фактических трудозатрат.
- **Расчет зарплаты:** почасовая оплата труда, учет ставок сотрудников, автоматическое формирование индивидуальных зарплатных ведомостей с ограничением прав доступа (пользователь видит только свою ведомость).

**Реализованные объекты метаданных:**
- *Справочники:* Сотрудники (с историей ставок), Проекты, Задачи.
- *Документы:* Назначение исполнителей задач, Отмена задач, учёт трудозатрат по задаче, выплата зарплаты.
- *Регистры сведений:* Ставки сотрудников (периодический), Исполнители задач, состояние задач исполнителей, Интервал по задачам.
- *Регистры накопления:* Оплаты сотрудникам.
- *Отчеты:* Анализ трудозатрат, Анализ сроков выполнения задач.

## 🚀 Как развернуть конфигурацию

**Вариант 1:** из XML-исходников (рекомендуется для разработчиков)

- Создайте новую пустую информационную базу в 1С:Предприятие.

- Запустите её в режиме Конфигуратор.

- В меню выберите Конфигурация → Открыть конфигурацию.

- Выберите Конфигурация → Загрузить конфигурацию из файлов...

- Укажите папку src/ из этого репозитория.

- Обновите конфигурацию базы данных (клавиша F7).

- Запустите 1С:Предприятие в режиме пользователя.

**Вариант 2:** из готового файла .dt (быстрый способ)

- Создайте новую пустую информационную базу.

- Запустите в режиме Конфигуратор.

- Выберите Администрирование → Загрузить информационную базу...

- Укажите файл dist/База конфигурации.dt.
